Adapter

CSSAdapter

La caccia ai bug CSS (F6). Passa il mouse su un elemento o premi S per trovare sforamenti del viewport, click bloccati da overlay o pseudo-elementi, z-index intrappolati in uno stacking context, testo invisibile, immagini deformate e regole !important.

Il Core non legge un solo foglio di stile. Riceve solo pacchetti, righe cliccabili e cause raggruppate.

Uso base

A differenza di WebDOMAdapter, CSSAdapter si registra sul Core spento di default (enabled: false), così non tocca la pagina finché non premi F6 o il pulsante F6 CSS nell'overlay.

app.js
import { BeeLadybugCore, CSSAdapter } from 'bee-ladybug';

const bee = new BeeLadybugCore();
const css = new CSSAdapter(bee);
css.attach();
// Premi F6 per accendere la caccia, S per scansionare la pagina, P per bloccare il pannello.

Puoi accenderla anche da codice con bee.toggleAdapter('css') o bee.setAdapterEnabled('css', true). Senza bundler, nell'import usa il percorso ./node_modules/bee-ladybug/src/index.js, come in Inizia.

Tasti della caccia CSS

Tasto Quando risponde Effetto
F6 Con overlay visibile Accende / spegne la CSS hunt (gestito dal Core tramite l'hotkey registrato).
S Con hunt accesa e overlay visibile Scansiona tutta la pagina (css.scan()), sblocca un eventuale pin e mostra i primi maxScan gruppi in Inspect.
P Con hunt accesa e overlay visibile Blocca / sblocca il pannello sull'elemento sotto il puntatore, disegna il contorno rosso e scorre l'elemento al centro dello schermo.

I tasti S e P usano event.code (KeyS e KeyP). Vengono ignorati quando scrivi in un input, textarea, select o contenteditable, quando premi combinazioni col browser (Ctrl+S, Cmd+S, Ctrl+P, Alt) e quando l'overlay è nascosto con F2.

Cosa rileva

In hover (F6), nella scansione (S) e nel report (F8), l'adapter esegue sei controlli in ordine di gravità (rank da 0 a 6), saltando sempre i nodi nascosti (display: none, visibility: hidden, box 0×0), la barra #wpadminbar, i tag script/style/link/meta e l'interfaccia di BeeLadybug:

Controllo Livello Come funziona
Overflow viewport error (rank 0) Segnala gli elementi che escono a sinistra (rect.left < -1) o a destra (rect.right > clientWidth + 1). keepOverflowCauses scarta i genitori che fanno solo da eco a un figlio (±2 px) o la cui larghezza ci sta nel viewport.
Click bloccato error (rank 1) Controlla il centro dell'elemento con document.elementFromPoint(x, y) e i pseudo-elementi ::before / ::after fissi o assoluti su html e body. Se un altro nodo copre il punto, raggruppa per causa (es. body::after blocks clicks on 10 elements).
Stacking context error (rank 1) / info (rank 6) Se un elemento ha z-index diverso da auto, risale gli antenati cercando chi crea uno stacking context (transform, opacity < 1, filter, oppure position !== 'static' con z-index !== 'auto') e raggruppa i figli intrappolati. will-change: transform / opacity viene segnalato come nota grigia (info), non come errore.
Testo invisibile error (rank 2) Su elementi con testo proprio (o button, a, label, input, textarea) controlla: opacity: 0 (anche ereditata da un antenato), colore con alpha 0 (transparent, rgba(..., 0)) e colore quasi identico allo sfondo dietro (scarto RGB < 2 e alpha < 0.05). Colori in sintassi non RGB (oklch, lab, color(), color-mix()) non generano falsi positivi.
Immagine distorta error (rank 3) Su <img> con object-fit: fill (il default CSS), confronta le proporzioni del file (naturalWidth / naturalHeight) con quelle del box renderizzato (getBoundingClientRect). Segnala errore se differiscono di oltre il 5%.
Regole !important warn (rank 4) Legge i fogli di stile attivi in document.styleSheets (saltando quelli con disabled === true o con media che non corrisponde) e trova le proprietà con priorità important che matchano l'elemento, indicando anche il foglio sorgente.
Margine negativo warn (rank 5) Segnala qualunque lato (margin-top/right/bottom/left) con valore finito minore di 0.

Un foglio di stile cross-origin che non permette la lettura di cssRules non viene contato come errore: produce una sola nota informativa grigia (unreadable sheet: …) per foglio.

Opzioni

I valori predefiniti sono esportati anche in CSS_ADAPTER_DEFAULTS.

Opzione Default Effetto
source 'css' Il source di tutti i pacchetti inviati al Core.
hotkey 'F6' Tasto registrato nel Core per accendere e spegnere la caccia.
scanKey 'KeyS' Codice tasto (event.code) per lanciare scan() a caccia attiva.
pinKey 'KeyP' Codice tasto (event.code) per bloccare/sbloccare il pannello sull'elemento corrente.
label 'F6 CSS' Etichetta del pulsante mostrato nell'overlay.
maxScan 8 Numero massimo di gruppi mostrati nella sezione Inspect dopo una scansione (S).
issueWindow 5000 Finestra di deduplicazione in millisecondi: lo stesso problema sullo stesso elemento viene scritto nella lista eventi al massimo una volta ogni 5 secondi.
maxIssues 10 Numero massimo di cause raggruppate mantenute nella lista fissa Issues.

Issues, Inspect e riquadri sulla pagina

Quando la caccia è attiva, CSSAdapter monta due riquadri leggeri nel body (data-bee-ladybug-css="hover" con bordo giallo #ffd36a e data-bee-ladybug-css="pin" con bordo rosso #ff3b4e) in pointer-events: none. Se nascondi l'overlay con F2, anche i due riquadri spariscono.

  • Issues (in alto nel pannello): tiene fino a maxIssues cause raggruppate (overflow, click bloccati, stacking context) più le note sui fogli cross-origin e will-change. Non scorre via con la console; cliccando una causa si espandono gli elementi coinvolti e cliccandone uno l'adapter ci scorre sopra e lo contorna in rosso.
  • Inspect: mostra i dettagli dell'elemento in hover (o i primi maxScan gruppi dopo S). Cliccando una riga si fissa il riquadro rosso sull'elemento.

Un MutationObserver osserva le modifiche a <style> e <link> e ricostruisce la cache delle regole !important solo quando cambiano i fogli di stile.

Cosa invia al Core

Tutti i pacchetti portano source: 'css'. Il formato generale è nel contratto sendData.

Tipo Quando Contenuto
state Accensione / spegnimento / ispezione Quattro chiavi HUD: css.hunt ('on' / 'off'), css.target (selettore o '—'), css.hits (numero problemi sul nodo, '0' fuori bersaglio), css.pin (selettore bloccato o 'off') e css.scan (numero gruppi trovati con S). Quando spegni la caccia, css.target, css.hits e css.pin vengono resettati.
error / warn Hover su un elemento con problemi Un pacchetto per problema (es. div.hero overflows viewport (right +120px)), limitato da issueWindow (uno ogni 5 s per coppia elemento/problema).
warn Scansione con S scan N issue(s). Click a row to outline it. (Se la pagina è pulita, invia scan clean solo quando è attivo F3 SLOW).
log Foglio cross-origin non leggibile unreadable sheet: https://… (livello info, una sola volta per foglio).
log Hover su elemento pulito con F3 SLOW attivo div.card clean (a velocità normale resta silenzioso).

Metodi e proprietà

Membro Cosa fa
attach() Si registra nel Core come css (etichetta F6 CSS, hotkey F6, enabled: false) e ascolta la visibilità dell'overlay. Restituisce this.
detach() Spegne la caccia se attiva, smonta i riquadri, pulisce Issues/Inspect e rimuove la registrazione dal Core. Restituisce this.
scan() Esegue la scansione dell'intera pagina quando la caccia è attiva (equivale a premere S). Se la caccia è spenta non fa nulla. Restituisce this.
snapshot() Esegue una scansione completa e silenziosa per il report (F8), anche con la caccia spenta, senza toccare log, pin o pannelli. Restituisce fino a 80 righe ordinate per gravità (error → warn → ok), oppure null se l'adapter non è attaccato.
css.active Getter booleano: true mentre la caccia CSS (F6) è accesa.

Nel report (F8)

Quando premi F8 o chiami bee.exportReport(), snapshot() popola la sezione css del report anche se non hai mai acceso F6. Le cause vengono prima raggruppate tutte e solo dopo l'ordinamento per gravità vengono tagliate al limite di 80 righe, così le note informative (will-change, unreadable sheet) non possono mai far scartare un errore reale.

Regola (rule) Gravità Esempio di valore
overflow error article#bleed overflows viewport
click blocked error div#mask blocks clicks on 2 elements
stacking context error div#hero creates stacking context (transform) - z-index of 1 child is trapped
invisible text error invisible text (color matches background)
distorted image error distorted image 33% (object-fit: fill)
!important warn !important .hot { color: red } ×2
negative margin warn negative margin margin-left: -8px
will-change ok div#hint will-change: opacity — z-index of 1 child stays in this layer
unreadable sheet ok https://cdn.example.com/app.css

Limiti

  • Proprietà abbreviate con !important: il CSSOM del browser espande le shorthand (es. margin: 0 !important) nelle singole proprietà longhand (margin-top, margin-right, margin-bottom, margin-left), quindi ognuna produce una propria voce.
  • Contenitori con overflow: hidden / auto: lo sforamento è misurato rispetto alla larghezza del viewport (documentElement.clientWidth); elementi posizionati fuori schermo dentro un carosello o un drawer chiuso possono comparire tra gli overflow.
  • Blocco del click al centro: pushBlockers campiona il punto centrale del rettangolo dell'elemento e i pseudo-elementi ::before / ::after su html e body.
  • Sfondi complessi: il confronto di contrasto (paintBehind) legge backgroundColor lungo gli antenati; non valuta immagini di sfondo o gradienti CSS.

▶ Prova in console

Apri una pagina qualsiasi, premi F12 e incolla (se Chrome blocca l'incolla, scrivi allow pasting e riprova). Lo snippet carica bee-ladybug@0.6.4 dalla CDN, attacca CSSAdapter, accende subito la caccia CSS e lancia una scansione della pagina:

console
import('https://cdn.jsdelivr.net/npm/bee-ladybug@0.6.4/src/index.js')
  .then(({ BeeLadybugCore, CSSAdapter }) => {
    const bee = new BeeLadybugCore();
    const css = new CSSAdapter(bee);
    css.attach();
    bee.toggleAdapter('css');
    css.scan();
    Object.assign(window, { bee, css });
  });

Nel pannello si popolano subito Issues e Inspect: clicca una riga per scorrere sull'elemento e contornarlo in rosso. Muovi il mouse per ispezionare i nodi dal vivo, premi P per fissare il pannello, S per riscansionare, F6 per spegnere la caccia e F8 per scaricare il report.
